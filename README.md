# Vehículo Inalámbrico a Control Remoto con ESP32

## Descripción
Proyecto de iniciativa propia enfocado en el diseño y programación de un vehículo (Rover) controlado de forma inalámbrica. El sistema utiliza un microcontrolador ESP32 para gestionar la tracción mediante algoritmos de dirección inteligente y control proporcional usando un mando externo.

## Hardware Utilizado
* **Microcontrolador:** ESP32
* **Actuadores:** 4x Motorreductores DC (carcasa plástica con engranaje metálico interno)
* **Estructura:** Chasis adaptado y optimizado
* **Driver de motores:** L298N

## Software y Librerías
* **Entorno:** Arduino IDE
* **Control Inalámbrico:** Librería `Bluepad32` para la vinculación y mapeo de controles Bluetooth.

## Características Técnicas Destacadas
* **Conducción Proporcional:** Mapeo avanzado de los joysticks analógicos para lograr una aceleración y control de velocidad suaves, evitando arranques bruscos.
* **Dirección Inteligente:** Algoritmo que calcula dinámicamente la diferencia de velocidad entre las ruedas laterales, permitiendo giros precisos en su propio eje.
